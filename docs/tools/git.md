# Git

## Commandes de base

- [Git Cheat Sheet](https://git-scm.com/cheat-sheet)

### Ajouter des fichiers

```bash
git add <file>
# ou
git add .
```

### Commit

```bash
git commit -m 'message'
```

### Changer de branche

```bash
git switch <name>
```

### Créer une branche

```bash
git switch -c <name>
```
